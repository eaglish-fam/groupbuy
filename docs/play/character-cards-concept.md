## 一、核心想法：先認識人，再看需要

現在的網站是「商品牆」：使用者進來先看到商品，要自己判斷「這跟我有什麼關係」。
反向介面把順序倒過來：

```
角色（像我嗎？）→ 他的一天（我也會這樣）→ 某個時刻的麻煩（我懂）→ 剛好派得上用場的東西（原來可以這樣）
```

使用者不是在逛貨架，而是在陪一個人過日子。商品出現的那一刻，已經有情境、有理由，所以不像廣告。

## 四、八角遊戲化框架怎麼用（Octalysis 8 Core Drives）

| 核心驅動 | 在這個頁面裡 |
|---|---|
| 1 使命與意義 | 使命是**角色自己的**：每位角色有一個目標（詩涵「讓小米安心學走路，自己也能喘口氣」），玩家是陪他完成目標的人；建立自己的角色時，目標就是玩家自己的。（Hiram 11/04 回饋：不要讓人覺得在幫我們工作。） |
| 2 進步與成就 | 每位角色有「目標進度」；陪完一天得到徽章；和大家的關係從「剛認識」到「老朋友」；收藏冊 x/8。 |
| 3 創意與回饋 | 每個時刻可以「選這個」「換一個看看」或「這個不需要」，角色立刻回一句話；「建立我的角色」五步（樣子、關於你、家裡有誰、目標、卡住的地方）產生自己的一天，可以玩。 |
| 4 擁有與佔有 | 角色收藏、徽章、購物清單、自己的角色（都存在自己的裝置）。 |
| 5 社交影響 | 「這就是我！」標記最像自己的角色；分享角色卡連結給朋友（手機用系統分享，電腦複製連結）。 |
| 6 稀缺與渴望 | **只用真的**：團購 Sheet 上真實的結束日期與倒數（3 天內轉成醒目顏色）。不做假倒數、不鎖內容。 |
| 7 好奇與未知 | 「抽一張角色卡」隨機遇見一個人；每天的時段逐段揭曉；中途隨機出現一張「意外事件」卡。 |
| 8 損失與避免 | 溫和使用：購物清單依「現在可以買／即將開團／先收著」分組，會顯示即將截止。不做「不買就失去」的話術。 |

原則：第 6、8 項（黑帽）只用真實資料，避免讓使用者覺得被操弄；以第 1–4 項（白帽）為主，讓人因為「被理解」而停留。

## 四之一、一天怎麼走（v2，Hiram 11/04 回饋後）

1. 每個時刻顯示「卡住的是：…」與兩個候選商品；候選不只一組時可以「換一個看看」，也可以「這個不需要」直接跳過。選過或跳過都能「改選」。
2. 一天走完出現「打包清單」：選過的商品預設勾選，玩家取消不要的，再「放進購物清單」。
3. 購物清單分「現在可以買（開團中，有前往團購）／即將開團／先收著」。
4. 商品卡的圖片可以左右滑動，圖片來自已發布的選物誌（`scripts/build-play-media.mjs` 產生 `play/product-media.json`，`npm run verify` 會重產並檢查）；「看更多」打開大圖（完整顯示、不裁切）、說明與「讀完整選物誌」。

## 四之二、入口與語音（v3，Hiram 11/04 第二次回饋）

- **入口儀式**：第一次進來先看到「每一頁，都是某個人的一天。」翻開後依序選：樣子、暱稱、年齡、生活節奏 → 有沒有小孩（有就幫每個孩子取名字、選年紀）、是否和長輩同住 → 毛孩（狗狗／貓咪／其他＋名字）→ 目標 → 卡住的地方（最多 3）。最後同時翻出「最像你的人」（依年齡、孩子年紀、節奏、目標、煩惱打分）和「你的角色卡」。也可以「先隨便看看」直接逛所有角色。
- **名字帶入故事**：自己的一天裡，場景與角色反應會用孩子的名字（依場景適合的年紀挑孩子），毛孩會出現在事件卡。名字只存在使用者裝置，不送任何地方。
- **語音**：預設 8 位角色的故事、每個時刻與角色台詞由 VoAI 事先產生（旁白詠芯；每位角色各自的聲音），`scripts/build-play-voice.mjs` 手動執行，送前送後核對點數。頁面有「聽故事」「▶ 聽」與「自動朗讀」，並註明「語音由 AI（VoAI）生成」。使用者自己的角色不念（名字不送 VoAI）。2026-11-04 共用 3,196 點。

## 五、資料與內容規則

- 商品只用品牌名對應團購資料：即時讀 Google Sheet「現正開團」（和首頁同一套 `catalog-core.js`），失敗時用 `config/catalog-snapshot.json`，並提示「開團狀態以首頁為準」。
- 開團中才出現「前往團購」，其他狀態只顯示狀態與生活筆記。
- 故事只寫角色的需求，不替商品寫規格、功效或價格；商品說明一律取自團購資料。保健食品的情境寫「先看標示、先問醫師或藥師」。
- 角色與故事是虛構的，頁面上有註明。不收集任何個人資料；進度、補給清單、暱稱只存在使用者自己的瀏覽器（localStorage）。
- 測試頁 noindex、不進 sitemap，不影響現有 SEO。

## 六之前的版本說明

第一版角色是 SVG 插畫（同一套畫法、每位角色有自己的主色、髮型、配件，有孩子的角色旁邊會出現小孩），不需要外部圖檔、手機上也清楚；商品卡沿用網站既有的商品圖。之後如果要更精緻的角色插畫，可以請 Lydia／設計夥伴依同一份角色設定出圖，替換 `play/play.js` 的頭像即可。
