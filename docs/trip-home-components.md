# 遠行所目的地首頁

`/trip/` 是多國目的地入口。國家頁負責地圖與區域選擇，城市／區域攻略負責景點、交通、雨備與行程；首頁不按發文日期排列，也不把某一國的行程當成全站主線。

## 資料與元件

- `trip/home-catalog.mjs`：國家、攻略短文案、封面、玩法與編輯排序。
- `scripts/build-trip-home.mjs`：共用國家卡、攻略卡、篩選器、metadata 與頁面組裝；接受 catalog 參數，不按國名或國家 ID 分支。
- `trip/home.css`：只作用於首頁的響應式版面與互動狀態。
- `trip/home.js`：在靜態內容上增加國家／玩法篩選與逐步展開。沒有 JavaScript 時仍可閱讀所有攻略並直接前往。
- `scripts/build-trip-destinations.mjs`：沿用既有建置入口，呼叫首頁 renderer；不再維護第二份首頁 HTML。

照片記錄包含來源檔路徑、實際尺寸、替代文字與選用的裁切位置。同一封面重用相同資料；來源權屬仍以既有媒體紀錄為準。首頁只使用已存在、已整理的自有旅行照片。

## 加入下一個國家

1. 先完成可開啟的國家頁及攻略頁，確認 canonical 與實景照片來源。
2. 在 catalog 加入穩定的 country ID、國名、URL、短介紹、封面與 guide IDs。
3. 加入各攻略資料，指定 country ID、canonical URL、封面與已有的玩法標籤。必要時新增共用 theme；不在 JavaScript 裡加入國名判斷。
4. 依編輯順序排列 guides，讓首批攻略反映不同目的地；國家內部順序由 guideIds 控制。
5. 執行首頁擴充測試與 `npm run verify`，並在手機／桌機看過實際圖片裁切、長標題、篩選與無結果狀態。

國家數、攻略數與選項由資料產生。第三國與十國測試都使用記憶體內的 fixture，不會加入公開 HTML、sitemap 或假「即將推出」入口。

## v2：探索圖集與預訂動線

首頁順序為世界圖集＋實訪照片 → 玩法／指南 → 安排旅程 → 品牌說明。

- 國家新增 `region`、`regionLabel`、`geography:{point:[longitude,latitude],isoNumeric}`。`scripts/trip-world-atlas.mjs` 在建置時使用同一 Equal Earth 投影畫國界及點位；瀏覽器不載入地圖 SDK。來源授權見 `trip-atlas-sources.md`。
- 國家清單預設六個，可按地區或展開全部；同時只顯示一個照片面板。超過四個或小螢幕下會重疊的點位改為非互動示意，由文字清單選擇，避免誤觸。110m 圖資省略的小國仍可有有效座標與國家入口，不捏造放大國界。
- 地圖選國家只切照片與相關活動；明確點「找這裡的玩法」才改指南篩選。指南篩選是獨立探索工具。沒有 JS 時國家面板、所有指南及既有來源連結仍可讀取。
- `trip/home-commerce.mjs` 管理活動、countryId／guideId 關聯、來源檔案及既有聯盟 URL。新增 offer 需核對商品、指南錨點、來源追蹤碼與 disclosure；`checkedAt` 是內容來源核對日期，不代表即時庫存。沒有已核對商品的國家只出現指南建議。
- Agoda 現在沒有可用的帳戶聯盟 URL，住宿卡僅提供規劃提示；不代表已接 Agoda。取得連結後才新增實際住宿入口與驗證。機票明示暫停，不載入舊搜尋頁或刷新程式。
- `capabilities` 記錄本候選的就緒狀態，尚非可切換啟用服務的 runtime 開關。未來恢復機票仍須接入票價有效期、錯誤、查核與追蹤契約，並另獲啟用授權；不可只把文字改成啟用。
- 本次沒有新增 analytics 事件。收益衡量方案在 Eliora 專案研究報告；點擊、下單、取消、完成與結算需分開，不能由本機 UI 測試推論營收。

`tests/trip-home-atlas.test.mjs` 覆蓋正式點位落地、十國渲染與清單／地區／面板／活動互動、新加坡小國、相鄰歐洲觸控衝突及既有聯盟來源。十國是 model/controller 測試，非十國已發布或真機實測。

## 驗證邊界

單元測試核對現有國家來源涵蓋、有效路由／資產、未知參照失敗、第三國擴充、HTML／JSON 逸出與首圖載入優先權。瀏覽器驗收另確認視覺裁切、觸控尺寸、篩選、展開、焦點與水平溢位；程式通過不能替代看過畫面。

首頁改動不修改國家地圖、個別攻略內容、既有 planner、憑證或資料來源。發布必須綁定已驗證版本的授權；本機候選與正式上線是不同狀態。
