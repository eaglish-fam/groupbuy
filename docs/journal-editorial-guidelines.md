# 鷹家選物誌寫作規範（常設）

適用：`/blog/` 底下所有選物誌文章（商品文、折扣碼文、知識文）。新稿、改稿、檔期更新都要遵守。遠行所的旅遊文另見 `docs/trip-editorial-guidelines.md`。

依據：Hiram 2026-11-20（台北）本人原話，Bingo 轉入 Kingdom GB-061：

> 「再來選物誌的部分……他很多還是寫說，比如說有些字、圖片，或者是團購那種是上一團結團的，這種東西就不能寫。你要以我們現在當下做的事情為主，不要再用這種 AI 的邊界跟推卸責任來寫文。」

## 一、以「現在這一檔」為主體

選物誌寫的是我們現在正在做的事，也就是當下這一檔團購、當下這個折扣碼。

- 動筆前先核對兩樣：
  - 當下賣場頁：檔期、品項、團購價、組合、贈品、免運門檻、物流、退換貨。
  - Sheet「現正開團」那一列：連結、開團日、結束日、類型。
- 核對到的事實直接寫進正文。
- 賣場和 Sheet 或我們自己的備註不一致時，以廠商賣場頁為準（`decisions/2026-10-22-hiram-vendor-page-wins`）。正文照賣場寫，Sheet 的差異回報給營運（Bingo）。
- 查不到的項目就去查，查不到就不寫。不要用一句免責話帶過。

## 二、不留上一團、已結團的舊資訊

以下這些地方，都不能再出現上一檔、前一次、已結團的檔期、舊賣場連結、舊 banner：

- 正文、標題、摘要、meta／og／twitter 描述、JSON-LD
- FAQ、圖說、alt
- 封面與內文圖、影片說明、連結

補充規定：

- **舊的家庭實拍可以留**，例如「我們家 2021 年開始用」。但要寫成使用心得，不能把上一檔的賣場規則、舊組合、舊關單日寫成這一檔的條件。
- **影片說明裡如果有舊賣場連結**，換影片或拿掉那段連結。不要留著再加一句「別點影片裡的舊連結」。
- **已結團、還沒有下一檔的文章**：
  - 不要再寫「本期至某日 23:59 關單」，也不要寫「到買物社查看當期團購」卻掛著過期檔期。
  - 改寫成現在的狀態：寫明「這一檔已經結束」，或只留選購方法，等下一檔確定後再補日期。
  - 購買鈕走既有的 sheet-offer。沒有開團時，它會自動顯示目前沒有開放中的團購。

## 三、不用 AI 邊界與推卸責任的寫法

正文不要出現下面這類把責任推回給讀者或廠商的句子：

- 「僅供參考」「以賣場／廠商當下為準」「請以開團後的賣場標示為準」「以當期賣場為準」
- 「未實測／無實拍／無法確認」「團購頁沒有寫清楚，以賣場為準」
- 「資料取自公開頁面」「實際規格以官方公告為主」「不代表官方立場」「不保證」「請自行確認」
- 「以下依既有資料整理」「規格與價格依某年某月某日賣場整理」「價格、庫存與實際內容可能調整，請回團購入口核對」

改寫方法：

| 不要這樣寫 | 改成這樣 |
|---|---|
| 價格依 11/10 團購賣場整理，以賣場當下為準 | 團購價 NT$X，滿 NT$Y 免運 |
| 電池型號與續航，團購頁沒寫清楚，以賣場為準 | 寫我們查到的；查不到就整句不寫 |
| 這次的出貨與退貨規則，請以開團後的賣場為準 | 黑貓／大榮配送、不送上樓、七天鑑賞期…（照當下賣場寫） |
| 選好款式，開團後到賣場確認 | 團購到 11/22，選好款式就能下單 |

購買按鈕維持既有的 `data-sheet-offer`／當期入口，不必在段落結尾再加一句「一切以賣場為準」。

**可以留的句子**：商品本身的客觀限制，寫成自然的提醒即可。例如：

- 18 吋行李箱可能超過部分航空的手提限制，登機前以地勤判斷
- 食品的過敏原請看包裝標示
- 洗滌照洗標

這類是商品說明，不是推卸責任。教學文的官方出處放在文末，正文寫我們實際走過的步驟，不要開篇先免責。

## 四、交件前自查

1. 用 grep 掃整頁，確認沒有這些字樣：`為準`、`上一檔`、`上一團`、`開團後`、`僅供參考`、`不保證`、`請自行`、`整理於.*賣場`、`依 20..\/..\/.. `。逐一確認剩下的都屬於第三節「可以留的句子」。
2. 檔期、價格、組合，和當下賣場、Sheet 逐項比對過；有差異的寫進交件說明。
3. 圖片、圖說、影片說明、外部連結，都確認是當下這一檔的。
4. 照常跑 `npm run verify`、開 PR、合併，再到正式站實點購買鈕。

## 五、作廢的舊指示

- GB-056 曾寫「本團價格、組合、贈品、出貨未拿到前一律『以賣場為準』」，作廢。沒拿到的資訊就先不寫，拿到再補。
