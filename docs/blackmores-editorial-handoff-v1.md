## 目標與範圍

`/blog/blackmores/` 為長期選購文章，以年齡、吃法、同單位含量比較五款魚油、葉黃素及LC-Plasma乳酸菌。只新增本文章、專屬樣式、商品裁圖與編輯文件；不改共用功能、商品映射、Google Sheet或其他文章。

## 一手來源與取捨

商品資料以2026-10-19查閱的Blackmores台灣官方五個商品頁、其食用標示及常見問題為準；LC-Plasma菌體性質另對照原料官方與Kirin產品資料。完整公開來源見文章頁尾及`blackmores-article-package-v4.json`。

- 機伶小子採完整標示的4歲以上、飯後咀嚼、切勿整顆吞嚥及成人監督；每顆Omega-3 300mg，EPA 180mg、DHA 120mg。
- 迷你濃縮魚油採官網每顆300mg Omega-3、約1.5公分及已列兒童分齡用量；省略未核完整標示的EPA/DHA分量。
- 兒童葉黃素採3–17歲、每錠5mg葉黃素與1mg玉米黃素，以及3–12歲、13–17歲不同每日錠數。
- 成人葉黃素為「金盞花葉黃素＋蝦紅素＋B6」，18歲以上每日隨餐1顆、上限1顆；省略未核毫克數。
- LC-Plasma為熱處理非活菌，採每包1000億「個」、每日1包與30°C以下乾燥避光保存；不寫成CFU或活菌。

無已核自有使用影片或體驗，不使用效果故事、疾病療效、吸收倍數或保護倍數。未核完整過敏原、營養數字及LC-Plasma年齡不補猜。短期價格、折扣、檔期不寫進永久文章或圖片。

## 圖片與製作檔

五張商品WebP由官方原圖自然矩形裁切，保留完整瓶蓋、瓶底或盒裝及標籤；剔除包裝外獎章、字幕與人物。來源URL、原始hash、裁切座標及成品hash見`blackmores-media-sources-v1.json`。

`/assets/blackmores/cover-source.html` 是一般HTML/CSS排版製作檔，使用實際商品裁圖，不重繪產品。預設畫布1600×1000；加`?mode=card`為1000×750。使用正常Chrome渲染後，分別輸出首圖與獨立商品卡；再由首圖產出480×300、960×600 WebP。必須目視確認中文字完整、標題與瓶底無重疊，以及包裝比例完整後才能採用。首圖與商品卡是不同製作畫布，不互相裁切替代。

## 工程接線與驗收

- 品牌精確查找值：`澳佳寶保健食品`；文章鍵：`blackmores`。
- 第二區塊的`data-blackmores-early`與文末`data-blackmores-offer`均先以普通`/#catalog`連結安全後備；由工程沿既有機制接上動態Sheet與浮動購買入口，不建立新資料源。
- 沿共用奶油底、宋體文章shell；目錄為真正的`nav[data-reading-nav]`錨點，已包含共用閱讀導航與文章目錄樣式。
- 單一H1、Organization作者、canonical、OG/Twitter與Article/BreadcrumbList對齊文章和首圖；未加入FAQPage、Product或Offer結構化資料。
- `bodyText`由實際HTML全部正文區塊抽取，包含標題、表格及每一個FAQ；不截斷。只排除導覽、按鈕、圖說、來源標號與例行頁尾。
- 文章套件與consumer-html機械檢查不代替實際畫面驗收。工程整合仍需商品卡／選物誌入口、sitemap、robots、動態購買控制與`npm run verify`；主責另親驗Tailnet桌機／手機、全部圖片、目錄、FAQ與購買入口。
