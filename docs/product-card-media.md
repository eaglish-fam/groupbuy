# 買物社商品卡首圖：滿版原圖

Hiram 於 2026-10-06 明確要求所有商品卡首圖滿版。適用首頁即時商品卡、載入前的靜態商品卡，以及相同元件的資源卡；手機、平板、桌機一致。

- 圖片貼齊卡片上緣與左右邊緣，不使用固定 4:3 容器搭配 contain 產生灰色／白色外框。
- 以真實圖片的原始比例決定高度：width:100%、height:auto、display:block。圖框與點擊按鈕同步依圖片高度，不拉伸、不為統一高度裁掉標題、人物或商品。
- 保留原始圖片、放大查看與詳情入口。此規則不代表可以重新生成或修改人物／商品，也不改動商品資料、連結或檔期。
- 不同長寬比可有不同卡片首圖高度；沿用既有手機雙欄 masonry，載入與尺寸改變時重新計算。
- 共用 CSS 的快取版本必須同步到首頁及首頁建置器，避免正式站仍讀到舊版型。

驗收不只檢查 object-fit：實際查看手機和桌機，確認圖片寬高等於圖框寬高、無外圍留白、文字與主體完整，且商品詳情仍可開啟。
