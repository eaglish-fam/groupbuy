# 紐西蘭地圖樣式與比例修正

日期：2026-09-28。範圍限紐西蘭國家入口的旅行地圖，本機候選，未發布。

## 變更

- 使用依 Natural Earth 紐西蘭輪廓參考重畫的第二版水彩底圖，修正第一版北島過大的比例；保留泰國地圖的奶油紙底、赭色陸地、棕色海岸、淡藍海水與山脈筆觸。
- 沿用泰國拱形框、紅色點位、米色中英標籤及 hover/focus 狀態。八個區域連結與下方照片卡仍通往相同攻略，無需 JavaScript 即可操作。
- 標籤左右錯開；手機左欄寬 26%，避免遮住皇后鎮點位，並採最少 44px 的文字點擊範圍。
- 全圖／北島／南島共用同一底圖，以 CSS 等比例裁切放大；點位與跨區順序線使用相同座標投影。桌機滑入選擇鍵、觸控點擊及鍵盤方向鍵/Home/End 均可切換，Tab 可直接進入所選島的地名。
- 北島顯示五個入口（奧克蘭、漢密爾頓、瑪塔瑪塔、羅托魯瓦、威靈頓），南島六區域；同步下方 2／6／8 張照片卡。威靈頓為獨立交通接續，南島內陸與東岸分支分開說明，並明示虛線非實際道路或一日行程。
- 底圖為生成示意插畫，非實訪照片；來源與地理參考記錄於 `trip/assets/new-zealand-atlas.source.json`。原始 PNG 留存於授權的專案素材目錄。

## 效能與內容影響

地圖原版 1254px WebP 79,976 bytes；640px 16,146 bytes；960px 29,058 bytes。使用固定寬高、srcset、lazy 與 low priority；sizes 依全圖／北島／南島的 1／1.75／1.85 倍實際放大尺度選取足夠解析度；保留每頁第一張實景照片的唯一 high priority。

未變更 canonical、索引政策、八篇文章內容、行程模型或對外來源事實；現有篩選器與地圖使用同一島嶼選擇狀態。地圖文字連結保留 aria-label 及鍵盤 focus；選擇鍵採 roving tabindex、降低動態效果設定受尊重；地圖明示為旅行位置示意，不能當作導航。

## 南島路線修正

修正東岸支線穿越海面，以及凱庫拉至基督城、中坎特伯雷至湖區的短跨水段。保持六區域點位和文章入口不變，加入陸地上的中繼折點，湖區段繞過底圖中的藍色水域。驗證直接讀取實際 WebP，每約 2 個原圖像素採樣；以暖黃色陸地／棕色岸線辨識，4px 鄰域容忍描邊與窄河細節。新南島兩條線的連續落水距離為 0，舊路線則能觸發回歸失敗；另由 Eliora 檢查實際瀏覽器呈現。
