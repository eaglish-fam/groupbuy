# 鷹家遠行所：旅行攻略參考架構

2026-09-27，Hiram 指定曼谷篇為後續旅行網誌的架構、風格與模式基準。

參考頁：[曼谷親子景點與行程](https://www.eaglish.store/trip/guides/bangkok-with-kids/)。基準是目前已確認的照片景點卡、奶油砂岩配色、互動試排行程、文章目錄與景點優先內容。新城市沿用這些原則，再依地理、天數與讀者需求調整；現有其他文章逐篇改版時採用，不因此批次重寫。

## 頁面架構

1. **首屏**：麵包屑、清楚的目的地與玩法標題、簡短導讀、署名／更新日、能看懂地點的實景主圖。照片優先呈現場景與活動。
2. **看圖挑景點**：短小、接近方形的照片卡，列名稱、玩法、建議停留時間；點擊跳到該景點介紹。寬版四欄，900px 以下兩欄，圖片比例 3:2。
3. **互動行程試排**：先選天數，再選「悠閒散步／緊湊」，查看某一天並更換區域。一次呈現所選日，避免全部變體展開成長表。天數依目的地設定，曼谷的 2～5 日不是所有城市的固定限制。
4. **景點詳解**：地點是什麼、玩什麼、實景圖片、實用資訊表、小標分段介紹、簡短實訪故事、Google Maps、票券選擇及行前來源。
5. **旅行配套**：餐食與交通銜接、整段雨備、FAQ，最後放完整影片及延伸閱讀。

手機保留可隨時回跳的文章目錄；目前定案為左側 36px 頁籤、左內距 7px、右內距 3px、隱藏箭頭。桌面保留側邊目錄。沿用 `/blog/reading-nav.js` 與對應樣式，並驗證鍵盤開關、焦點、目前閱讀位置與小螢幕閱讀空間。

## 視覺風格

資訊卡、表格與試排工具使用奶油砂岩；照片提供旅行的活潑感，橘紅作為小面積訊號。避免把資訊區改回大片藍色、飽和黃色或裝飾性漸層。

| 用途 | 基準色 |
| --- | --- |
| 砂岩卡片 | `#f2eee5` |
| 奶油資訊區 | `#faf7f0` |
| 紙白底色 | `#fcfaf5` |
| 深可可文字 | `#494139` |
| 分隔細線 | `#dcd5c9` |
| H3 暖棕標題 | `#784b39`，700 字重，搭配 `#bb7658` 3px 左線 |

字型與標題層級沿用現行 `trip/trip.css`；品牌標誌使用已核准資產。H3 必須能和正文立即區分。卡片採 3px 小圓角、短文案與緊湊間距；不要做成後方大片留白的滿版文字列。按鈕與選單保留明確焦點及足夠觸控面積；選取狀態不可只靠顏色辨識。

## 讀者與內容

- 先服務沒看過鷹式一家影片、正在安排旅行的讀者。
- H1 和 H2 說清楚城市、景點、玩法與行程，不用抽象生活感言當標題。
- 每個景點回答：是什麼、玩什麼、怎麼去、留多久、雨天是否適合、門票如何選。
- 影片是實訪證據和素材來源，不是文章目錄。每站家庭故事以一小段為限。
- 可重組實訪點，但明確區分「我們去過」與「編輯延伸建議」，不虛構連續行程。
- 語氣具體、輕快。刪除無資訊的排比、對比及「留白」「享受旅程」式泛泛結語。

## 圖片

- 首屏讓讀者看到目的地或活動，而非一張正在講話的人像截圖。
- 使用自有照片、適合獨立觀看的影片場景，或已確認用途的官方合作素材。
- 先挑無字幕畫面；必要時裁掉字幕區，不虛構被裁掉的景物。
- 不把平台旅客評論照片當成官方素材；官方圖的來源與使用條件另留紀錄。
- 一張圖應幫助理解地點或活動。圖片替代文字描述實際畫面，不塞 SEO 關鍵字。
- 保留影片 ID、秒數、裁切與圖片校驗資訊；公開頁不顯示私有工作路徑或模型處理紀錄。

## 可重用資料

- `trip/data/bangkok-places.json` 是曼谷八個實訪景點與餐廳的共用資料；城市頁卡片、文章與行程引用同一組穩定 ID。新城市另建自己的資料。
- 景點維持穩定 ID，玻璃底船是 SEA LIFE 的活動，不重複建成另一個地理景點。
- 停留時間標為編輯建議；營業、票種與交通附來源及核對日。
- 訂票連結和 affiliate 狀態分開記錄。不抄其他網站的追蹤碼，不沿用過期折扣或報成最低價。
- 行程須依開館／最後入場、預約場次、停留、車程、用餐與休息排時間。早上晚開的點不能硬排早場，晚間行程需確認可入場；同趟不重複安排相同景點。
- 每站保留 Google Maps 連結、時間來源與核對日，讓讀者行前覆核臨時調整。營業時間與建議停留分欄，不能混為一談。
- 互動選單須真正改變日程；替換已選區域時避免重複，變更天數時保留合理選擇。無 JavaScript 時仍能展開閱讀靜態路線。
- 目前未實作收藏、拖拉或跨次保存；後續有完成能力再出現對應操作，不能沿用尚未可用的按鈕。

## 圖片載入與共用實作

- 遵循 `trip/IMAGE_PIPELINE.md`：壓縮 WebP、響應式尺寸、固定寬高；保留原圖作素材。
- 頁首預載第一張旅遊主圖，只有這張使用高優先權；其他首圖降低優先權，後段圖片延後載入。預載與圖片的 `srcset`、`sizes` 必須一致，避免重複下載。
- 新頁面接入 `scripts/trip-image-priority.mjs` 及圖片檢查；不要在文章中自行加入一批高優先權圖片。
- 曼谷參考實作：`scripts/build-trip.mjs`（頁面）、`scripts/trip-bangkok-places.mjs`（景點）、`scripts/trip-bangkok-routes.mjs`（路線）、`trip/bangkok-planner.mjs` 與 `trip/bangkok-planner-model.mjs`（互動）、`trip/bangkok.css`（視覺）。後續重用時抽出共用部分，地點、來源、聯盟連結與路線規則保留在各城市資料中。

## 發布驗收

- 原文章網址、內部錨點、canonical、OG 與 Article/Breadcrumb 結構資料一致。
- 逐張檢查字幕、清晰度和主體；測試手機無橫向溢出、圖片載入、目錄和展開資訊。
- 新城市先用真實素材做出一篇完整範例，驗收後再擴大；文案、地圖、營業時間、票券與圖片都需對到該城市，不能繼承曼谷資料。
- 全站 `npm run verify` 通過，檢查變更範圍；修改文章本身不自動新增商店入口或改動其他城市內容。
