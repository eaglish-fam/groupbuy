# Wave 與 ARTISAN CB301 文章內容基線

日期：2026-09-08
狀態：正式發布基線

## 共用寫作路線

- 目的：先讓讀者認出自己的生活情境並產生好奇，再理解產品是否適合；不是把團購頁規格搬成長文。
- 框架：生活摩擦 → 反常識或未完成問題 → 真實素材證明 → 使用選擇 → 常見疑問 → 即時團購入口。
- 圖片：商品與可驗證的使用結果維持來源像素；不生成不存在的產品、配件或效果。
- 商業資訊：文章不凍結價格、庫存與檔期；CTA 每次從「現正開團」Sheet 重新核對。
- 狀態：首頁依最新 Sheet 自動將文章放入「開團中」「即將開團」或「選物文章」。

## Wave 鷹嘴豆泥

- 好奇鉤子：吐司吃膩了，也許不是吐司的問題。
- 購買情境：想讓早餐、點心或一盤熟悉的料理有變化，但不想多做一道菜。
- 經證實機制：冷凍保存；退冰拌勻後可抹、沾、拌；成分含鷹嘴豆、白芝麻醬、橄欖油、檸檬汁、蒜頭、海鹽。
- 禁用：高蛋白、低 GI、低卡、減重、控糖等未有產品層級證據的主張。
- 素材：Wave 實際包裝、吐司、皮塔餅、菇類搭配照片。

## ARTISAN CB301

- 好奇鉤子：浴室真正難刷的，通常不是最髒的那一塊。
- 購買情境：浴室清潔因高處、地面、浴缸與細部位置反覆更換姿勢和工具而拖延。
- 經證實機制：約 50–104 公分伸縮長桿、手持模式、兩段轉速、六種刷頭；不同表面需選擇合適刷頭。
- 安全邊界：IPX7 不等於可長時間浸泡；充電前保持乾燥；清潔劑使用後沖淨刷頭。
- 素材：已核准導購圖、長桿使用情境、配件全貌與刷頭表面對應圖。
- 同列影片邊界：Sheet 影片是 LM3000 美腿機，不得沿用在 CB301 清潔刷文章；同一團購列可共用購買入口，不代表兩個產品可共用內容素材。

## 封裝決策

本次先以兩篇實作驗證寫作路線，不立即把它宣告為正式新 Skill。待 Hiram 確認文章的好奇感、溫度與轉換方向後，再把有效結構封裝為商品部落格專用 Skill，避免固化尚未驗證的語氣。
