# 鷹式一家生活筆記 `/blog/` 候選

狀態：本機候選，未部署；首頁與文章仍保留 noindex/nofollow。

## 公開資訊架構

- `/blog/`：生活筆記首頁。
- `/blog/<article-slug>/`：永久文章網址；目前第一篇為 `/blog/atojet/`。
- `/articles/atojet/`：noindex 相容轉址，避免舊候選路徑形成重複內容。
- `/`：既有團購首頁，不被 blog 候選取代。

## 首頁排序

1. 開團中：Google Sheet 當日已開始、尚未結束且購買網址有效。
2. 即將開團：有可解析的未來開團日期，不顯示未生效購買連結。
3. 選物文章：已結團的永久文章；Sheet 缺失、重複、日期無效或讀取失敗時，標示「團購狀態待確認」，不使用舊狀態。

首頁只列入已存在且可閱讀的 article catalog，不為 Sheet 中尚未完成文章的商品建立空殼頁。再次開團時沿用文章網址，只更新狀態與當期團購入口。
