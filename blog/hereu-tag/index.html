先找回從容

不是東西多貴，
是出門前真的不想再翻一次。

鞋子穿好了，鑰匙卻不見了。包包昨天明明放在這裡，今天要出門才發現換了位置。這種小混亂不一定造成損失，卻很容易把一天的心情打亂。

Hereu Tag 智慧定位器是搭配 Apple「尋找」使用的物品防丟標籤：近處讓它發聲，遠處查看網路回報的位置。它適合替鑰匙、行李和背包留下找回線索，不是能持續顯示移動路線的即時 GPS 追蹤器。

拿到以後，先做這件事

不用另外下載 App，
從 iPhone 的「尋找」開始。

這款 Hereu Tag 使用 Apple「尋找」網路，並非 Android 款。先確認 iPhone 已登入 Apple 帳號、開啟藍牙並能連網，再把 Tag 放在旁邊。第一次不要急著塞進行李，先在桌上完成設定。

  1. 依盒內說明開啟 Tag，確認聽到提示音。
  2. 打開「尋找」→「物品」，點加入按鈕，再選「加入其他物品」。
  3. 找到 Wireless tag 後連接，取一個好認的名字，例如「家門鑰匙」或「藍色行李箱」，再選圖示並完成註冊。
  4. 留在物品頁面，試按「播放聲音」。確認叫得響，再掛到真正要找的物品上。

如果一次買了好幾顆，就一顆設定完再換下一顆；不要只叫「Tag 1、Tag 2」，等到急著找東西時，你會感謝自己有把名字取清楚。

想跟著畫面操作，可以直接看上方教學；搭配 Apple 的加入物品說明，找選單會更容易。

近處和遠處，找法不一樣

先看位置的時間，
再決定下一步。

覺得鑰匙就在家裡？打開「尋找」選那串鑰匙，在可連線範圍內播放聲音，再循聲找沙發縫、外套口袋。這比盯著地圖上的住家地址有用。聲音也可能被厚包包蓋住，找到後可以換個好聽見的位置。

如果物品不在身邊，就看地圖和最後回報時間。Tag 仰賴附近參與「尋找」網路的 Apple 裝置協助回報；沒有人經過、訊號受阻或設備離線時，位置可能不會更新。地圖上的點是線索，不代表物品此刻仍在那裡，也不能告訴你放在第幾樓、哪個抽屜。

暫時找不到時，可依「尋找」提供的選項開啟找到時通知，或啟用遺失模式、留下願意公開的聯絡方式。有新位置先判斷再行動；懷疑遭竊時，不要單憑地圖自行追人。

一顆，留給一件常找的東西

除了鑰匙，還能放在哪裡？

行李箱：多一個抵達線索

放在固定內袋，出發前確認電量與連線。落地後看位置是否有更新，可以輔助了解行李的動向，但不能當成航空公司的即時行李系統；遇到延誤，仍要保留行李條、向櫃台申報。

背包：縮小回頭找的範圍

把 Tag 固定在內袋，不要鬆鬆丟在最容易倒出來的位置。發現包包不見，先分辨最後位置是辦公室、餐廳還是住家，再聯絡店家或回頭尋找。

共用鑰匙或器材袋：不用只問一個人

家人使用相容的系統與帳號時，可在物品頁的共享功能邀請對方。共享的是物品位置；事先講好用途，避免把找物工具變成偷偷查看別人行蹤的方式。

至於孩子或寵物，它最多只能提供附帶物品的線索，不能代替看顧或即時安全定位。想解決的是走失風險，就不要只靠一顆 Tag。

不必天天充電，也別完全忘了它

換電池、換主人，
都有一個小步驟。

Hereu Tag 使用可替換的 CR2032 鈕扣電池。看到低電量提示就更換；長途旅行前，也值得試一次播放聲音。用附帶開殼片開啟外殼，換上電池時正極朝上，闔好後重新測試。新舊鈕扣電池都要放在孩子拿不到的地方。

原廠標示 IPX6 防水，不等於可以泡水。遇雨後擦乾，別跟著衣服丟進洗衣機；要送給別人時，先由原持有人在「尋找」移除物品，再依原廠步驟重置，對方才能重新綁定。

買以前，你可能也想問

Hereu Tag 常見問題

配對一直找不到 Tag，怎麼辦？

先確認有開機聲、電池正常、手機藍牙已開，再靠近配對。若是別人用過的 Tag，請原主人先解除綁定；不要反覆重置，卻漏掉帳號仍綁著這一步。

能像 AirTag 一樣顯示方向和距離嗎？

不能因為同樣使用「尋找」，就把 AirTag 的「精確尋找」算進來。這款 Hereu Tag 的找物方式是查看回報位置與播放聲音，不是靠 UWB 箭頭一路指到物品旁。

怎麼選需要幾顆？

先列出真正會反覆找的物品，一件配一顆即可。鑰匙、行李和工作包是不同用途；若只想試用，從每天一定帶出門的那件開始，比為了組數分散放著更實際。
